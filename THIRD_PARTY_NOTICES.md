# Bibliotecas e fontes de terceiros

Este repositório inclui cópias das bibliotecas e fontes abaixo, para o site funcionar sem internet. Cada uma segue a própria licença, e nenhuma delas está coberta pela licença MIT do código deste projeto.

| [GSAP](https://gsap.com) | 3.15.1 | `js/vendor/gsap.min.js` | [GSAP Standard License](https://gsap.com/standard-license) (GreenSock) |
| [Lenis](https://github.com/darkroomengineering/lenis) | 1.3.27 | `js/vendor/lenis.min.js` | MIT (darkroom.engineering) |
| [Fraunces](https://github.com/undercasetype/Fraunces) | via Fontsource | `assets/fonts/fraunces-*.woff2` | SIL Open Font License 1.1, texto em [`assets/fonts/LICENSE-Fraunces.txt`](assets/fonts/LICENSE-Fraunces.txt) |
| [Inter Tight](https://github.com/rsms/inter-tight) | via Fontsource | `assets/fonts/inter-tight-*.woff2` | SIL Open Font License 1.1, texto em [`assets/fonts/LICENSE-InterTight.txt`](assets/fonts/LICENSE-InterTight.txt) |
